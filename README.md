# Frieren Continental Railway Network (MAGE-RAIL)

Interactive route planner and map for the Frieren Continental Railway Network.

## Features

- **Interactive Map & Station Search**: Explore lines, stations, and connections across the continent.
- **Route Planning Engine**: Schedule-aware journey planning with transfer optimization.
- **Detailed Timetables & Services**: Train classes (Komet, Adler, Falke, Reiher, Seelenzug, Regional, etc.).
- **Built with Modern Tech**: React 19, Vite, Tailwind CSS, TypeScript, and Lucide icons.

## Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm

### Installation

```bash
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build the application:

```bash
npm run build
```
